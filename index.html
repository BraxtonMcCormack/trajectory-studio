Data format

Sampled heliocentric positions in the ecliptic frame. Units: AU, days from epoch. Rows are [days, x, y] or [days, x, y, z].

{
  "name": "My Mission",
  "epoch": "2030-01-01",
  "target": "Alpha Centauri",
  "trajectory": [
    [0,     1.00,  0.00,  0.00],
    [30,    1.05,  0.15,  0.01],
    [60,    1.11,  0.29,  0.02]
  ]
}

Get real vectors from JPL Horizons (vector table, ecliptic frame). Drag on the canvas in 3D mode to rotate the view.
